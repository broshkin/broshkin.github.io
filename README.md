# broshkin.github.io

Портфолио Андрея Григорьева, Unity-разработчика. Живёт на <https://broshkin.github.io>.

Статический сайт: ни сборки, ни зависимостей, ни внешних запросов. Открывается
как есть, правится как есть.

## Что где лежит

```
index.html            главная: проекты, опыт, навыки, контакты
projects/*.html       страница на каждый проект с разбором
assets/css/site.css   все стили
assets/js/site.js     переключатель языка и фасад ютуб-трейлера
assets/media/         постеры, скриншоты и зацикленные mp4
assets/cv/            резюме в PDF, русское и английское
404.html
docs/superpowers/specs/  дизайн-документ сайта
```

## Как это править

**Текст.** Русский и английский лежат рядом в одном файле:

```html
<p><span lang="ru">Русский текст</span><span lang="en">English text</span></p>
```

Видимость переключает CSS по атрибуту `lang` на `<html>`, а `assets/js/site.js`
меняет этот атрибут по кнопке и запоминает выбор. Правя текст, правьте обе
версии сразу — они в соседних строках именно для этого.

Прямая ссылка на английскую версию: `?lang=en`.

**Новый проект.** Скопируйте любой файл из `projects/`, они собраны по одному
скелету: медиа → факты → задача → что делал я → как устроено → результат.
Добавьте карточку в сетку `.projects` в `index.html`.

**Медиа.** Видео — беззвучные зацикленные mp4, а не gif: та же картинка весит в
разы меньше. Как сделать петлю из трейлера:

```
ffmpeg -ss 12 -t 12 -i trailer.mp4 -an -vf "scale=960:-2,fps=24" \
       -c:v libx264 -crf 30 -preset slow -movflags +faststart loop.mp4
```

**Публикация.** Любой коммит в `main` уезжает на GitHub Pages сам, минуты за
две.

## Свой домен

Положить файл `CNAME` с одной строкой (`example.com`), у регистратора добавить
записи `A` на адреса GitHub Pages, в настройках репозитория включить *Enforce
HTTPS*. Сайт при этом не меняется.
