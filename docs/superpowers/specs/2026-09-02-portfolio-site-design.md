# Портфолио Андрея Григорьева — дизайн

Дата: 2026-09-02
Статус: утверждено в диалоге, реализуется

## Задача

Заменить портфолио на Tilda (`andreygrigoryev.tilda.ws`) собственным статическим
сайтом на GitHub Pages. Бесплатно, без сборки, без внешних зависимостей.

### Что не так с текущим портфолио

- Нет Figure Spider, Yummy Universe, Monopoly Defense — то есть половины работ,
  включая сильнейшую.
- Нет навыков, опыта, ни слова про WebGL и оптимизацию.
- Школьный тон: «для индивидуального проекта в школе 10 класс (оценка 5)»,
  «сделанная на коленке». Опечатка «Untiy».
- Проекты — голые ссылки на билды, без разбора задачи и решений.
- Ссылки на Google Drive и Telegram вместо страниц проектов.
- Домен `.tilda.ws` и рекламный футер Tilda.
- Только русский язык.

## Решение

Статический сайт: витрина + отдельная страница на каждый проект.

### Хостинг

Публичный репозиторий `broshkin/broshkin.github.io`, GitHub Pages включается
автоматически для репозитория вида `<user>.github.io`. Адрес — `https://broshkin.github.io`.
Свой домен можно прикрутить позже через `CNAME`, сайт от этого не меняется.

### Структура

```
index.html                  витрина
projects/figure-spider.html флагман
projects/berloga.html
projects/physics.html
projects/drift-escape.html
projects/yummy-universe.html
projects/monopoly-defense.html
assets/css/site.css
assets/js/site.js
assets/media/<проект>/
assets/cv/
404.html
```

### Два языка

Текстовые узлы дублируются: `<span lang="ru">…</span><span lang="en">…</span>`.
Разметка, картинки и структура общие — дублируется только текст. Видимость
переключает CSS по атрибуту `lang` на `<html>`:

```css
:root[lang="ru"] [lang="en"] { display: none }
:root[lang="en"] [lang="ru"] { display: none }
```

JS переключает `documentElement.lang`, запоминает выбор в `localStorage`,
понимает `?lang=en` и на первом визите смотрит на язык браузера.

Компромисс принят осознанно: поисковик видит одну страницу вместо двух. Для
портфолио, которое отправляют ссылкой, это неважно, а взамен нет сборки и обе
версии лежат рядом — английская не отстанет от русской незаметно.

Сайт обязан оставаться читаемым без JS: по умолчанию `<html lang="ru">` уже
стоит в разметке, поэтому без скриптов открывается полная русская версия.

### Главная

Хиро → о себе → навыки → **проекты** → опыт → олимпиады и награды → контакты.

Проекты идут сразу после короткого вступления: человек пришёл смотреть работы,
а не читать биографию.

### Страница проекта

Одинаковый скелет: медиа во всю ширину → мета-строка (движок, платформа, срок,
роль, размер команды) → Задача → Что делал я → Техническое решение → Результат →
галерея → ссылки на билд, репозиторий, трейлер.

Основа текста — README публичных репозиториев: там уже есть честный разбор кода
и раздел «что бы я сделал иначе». Этот раздел сохраняем: он показывает рост, а
не слабость.

### Контент

Честная версия резюме: без Thunder Lotus и Яндекс.Игр как мест работы. Опыт —
независимая разработка, Компьютерная Академия ТОП, Basket Entertainment. Город —
Санкт-Петербург.

Про Яндекс.Игры: Drift Escape там выходил и был снят с платформы. Пишем ровно
так, без умолчаний и без преувеличения.

### Медиа

Зацикленные беззвучные mp4 вместо gif (в 5-10 раз меньше при той же картинке),
у каждого — постер-кадр. Источники: трейлер Berloga и трейлер Yummy Universe из
Telegram-канала и с рабочего стола, скриншоты Figure Spider с itch.io, стиллы из
Telegram-канала. Всё лежит локально в репозитории — внешних загрузок нет.

Трейлеры на YouTube (Berloga, Let's learn physics!, Yummy Universe)
подключаются фасадом: постер с кнопкой, iframe подгружается только по клику.
До клика страница не ходит на сторонние домены.

### Визуал

Тёмная тема, один акцентный цвет, крупная типографика, много воздуха. Системные
шрифты — ни одного внешнего запроса. Скриншоты игр на тёмном фоне читаются
лучше всего.

## Ограничения

- Ноль зависимостей: ни фреймворков, ни CDN, ни сборки.
- Вся страница открывается без JS, кроме переключателя языка.
- Адаптив от 360px.
- Каждый факт на сайте должен быть подтверждён README, каналом или билдом.

## Проверка перед сдачей

- Все внутренние и внешние ссылки отвечают.
- Обе языковые версии полны: ни одного блока без пары.
- Вёрстка на 390px и 1440px.
- Вес главной страницы.
- Сайт открывается по `https://broshkin.github.io`.

## Открытый вопрос

У Monopoly Defense нет ни публичного репозитория, ни описания — только билд на
Unreal Engine 5 в папке «Билды». Без фактов от Андрея страница будет пустой.
Пока делается карточка со ссылкой на билд; полная страница — после того, как он
расскажет, что это за проект и что делал именно он.
